Jan – May 2026

Hindi Transliteration Engine — Seq2Seq + Attention

Duration
Jan – May 2026
Mentor
Jaideepsinh Raulji
Dataset Size
84,000+ Pairs

Built an NLP-based Hindi transliteration engine to convert Hinglish (Roman script) text into Hindi Devanagari script using Seq2Seq and Transformer architectures. Trained eight different deep learning model variants on 84,000+ character-level text pairs and evaluated performance using CER (Character Error Rate), WER (Word Error Rate), and BLEU score metrics. Implemented Beam Search decoding (width=5) and deployed the final model using FastAPI with a custom frontend interface.
