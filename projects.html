AI Chatbot & Agents
Saarthi AI — Personal AI Mentor

A production-grade personal AI mentor with long-term vector memory, multi-agent orchestration, and automated learning roadmaps.

Students lack personalized, persistent AI guidance that remembers their learning history and adapts over time. Generic chatbots forget context after every session.

Custom user interaction logs, learning path templates, and semantic embeddings derived from 100K+ educational Q&A pairs stored in a pgvector-powered vector database.

Designed a multi-agent pipeline: a Planner agent orchestrates tasks, a Memory agent queries vector store for context, and a Learning agent generates adaptive roadmaps using Gemini LLM.

FastAPI backend · Streamlit frontend · Gemini API · Supabase (pgvector) · PostgreSQL · JWT authentication · Python 3.11

Multi-user isolation with secure JWT sessions. Sub-second semantic memory retrieval. Adaptive learning roadmaps updated dynamically based on user progress milestones.

Demonstrates production-ready agentic AI architecture. Applicable to personalized education platforms and corporate knowledge management systems.

RAINWISE V3.1 — Real-Time Flood Detection

Real-time flood segmentation and multi-threat detection system using deep learning, achieving 98.89% accuracy optimized for edge devices.

Flood disasters cause massive loss of life due to delayed detection. Existing monitoring systems are slow, single-purpose, and not deployable on affordable edge hardware.

Custom flood imagery dataset (aerial + ground). Annotated segmentation masks for SegFormer training. Weather time-series data for LSTM forecasting (5+ years of historical records).

Three-component pipeline: SegFormer-B0 for pixel-level flood segmentation, YOLO-World for zero-shot multi-threat detection, and LSTM for 6-hour ahead forecasting.

PyTorch · SegFormer-B0 · YOLO-World · SigLIP · LSTM · OpenCV · Apple Silicon optimization (MPS) · Python

98.89% detection precision. Real-time inference on Apple Silicon. Multi-threat detection (vehicles, people, infrastructure) without retraining. LSTM forecasts flood risk 6 hours ahead.

Deployable on low-cost edge devices for disaster early warning. Presented at university research showcase. Applicable to smart city infrastructure and climate resilience planning.

NLP & Deep Learning
Hindi Transliteration Engine

Seq2Seq neural network converting Hinglish text to Devanagari script. Trained on 84K+ pairs with attention mechanism and beam search decoding.

Millions of Hindi speakers type in Hinglish (Roman script) but need content in Devanagari. Existing tools rely on dictionaries and lack NLP-based contextual accuracy.

84,000+ Hinglish → Devanagari text pairs from custom curated corpus. Character-level tokenization. 80/10/10 train-validation-test split with balanced phoneme distribution.

8 deep learning architectures evaluated: LSTM Seq2Seq with Luong attention, Transformer encoder-decoder, and hybrid models. Final model uses beam search with width=5 for output.

TensorFlow · Keras · FastAPI REST API · Custom HTML/CSS frontend · NumPy · Matplotlib (visualization) · Python 3.10

Best model evaluated on CER (Character Error Rate), WER (Word Error Rate), and BLEU score. Deployed via FastAPI with real-time inference. Sub-200ms response time.

Useful for digital inclusion of Hindi speakers. Demonstrates end-to-end NLP pipeline from data preparation to model deployment. Extensible to other Indic language pairs.

TensorFlow NLP Seq2Seq FastAPI Beam Search

IoT & Computer Vision
GreenSort — Smart Waste Management

AI + IoT waste classification system using YOLO and Random Forest, connected to Raspberry Pi servo-motor sorting hardware. Published at SustainX 2026.

Manual waste sorting is inefficient, expensive, and error-prone. Most waste ends in landfills due to improper sorting at source, causing severe environmental damage.

Custom photographed waste dataset: 4 categories (plastic, metal, paper, organic). 3,000+ images with bounding box annotations. Data augmentation applied for class balance.

Camera captures waste item → YOLO detects and classifies → Random Forest validates class → Raspberry Pi GPIO controls servo motors to physically sort the item into correct bin.

YOLO (custom trained) · Random Forest (Scikit-learn) · OpenCV · Raspberry Pi 4 · Arduino · Servo motor control · Python

~75% sorting accuracy across 4 waste categories. Real-time inference at 15 FPS on Raspberry Pi. Automated sorting triggers servo motors within 0.3 seconds of detection.

Research paper published at SustainX 2026 symposium. Demonstrates bridge between AI computer vision and physical IoT actuators. Scalable to smart city waste infrastructure.
