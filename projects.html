E-Commerce Data Pipeline

An automated ETL pipeline designed to handle high-velocity e-commerce transaction data, process it in real-time, and load it into a data warehouse for analytics.

Built a robust ETL workflow using Apache Airflow to orchestrate data extraction from various APIs and flat files.
Utilized PySpark for distributed data transformation, cleaning anomalies, and aggregating sales metrics before loading into PostgreSQL.
