Computer Vision

RAINWISE V3.1 — Flood Detection

Advanced real-time flood monitoring and segmentation framework. Leverages state-of-the-art vision transformers and zero-shot detection to identify flood boundaries and evaluate threat levels from camera feeds.

Traditional flood detection relies on slow, expensive physical sensors. Visual detection systems struggle with lighting changes and water reflections.
Utilized SegFormer-B0 for robust semantic segmentation of water bodies, coupled with YOLO-World for zero-shot object detection (people, vehicles in danger).
Achieved 98.89% detection precision. Capable of real-time processing on edge devices for immediate disaster response alerts.
PyTorch SegFormer YOLO-World OpenCV

NLP & Deep Learning

Hinglish to Devanagari Engine

A highly accurate transliteration system that converts romanized Hindi (Hinglish) into native Devanagari script. Built from scratch using sequence-to-sequence deep learning architectures.

Curated and preprocessed a massive parallel corpus of 84,000+ Hinglish-Devanagari text pairs, handling spelling variations and phonetic ambiguities.
Implemented an Encoder-Decoder Seq2Seq model with Attention mechanism in TensorFlow. Utilized beam search decoding for optimal character prediction.
Significantly outperformed baseline dictionary lookup methods, correctly predicting complex phonetics with high accuracy. Exposed as an API via FastAPI.
TensorFlow Keras Seq2Seq NLP
